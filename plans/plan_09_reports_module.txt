Expense Tracker - Module 6: Reports & Analytics Module Plan
=============================================================

Module Name: Reports & Analytics
File: plan_09_reports_module.txt

---


Overview
--------
Provides detailed financial reports and analytics. Users can view expense reports,
income reports, monthly comparisons, and category-wise breakdowns.
Reports can be filtered by date range and exported to CSV or PDF.

---


Pages / Views
-------------

1. Reports Dashboard
   Path: views/reports/index.php
   Shows: report type selection tabs, filter form, report content area

2. Expense Report Page
   Path: views/reports/expense_report.php
   Shows: expense breakdown with charts and tables

3. Income Report Page
   Path: views/reports/income_report.php
   Shows: income breakdown with charts and tables

4. Monthly Comparison Report
   Path: views/reports/monthly_report.php
   Shows: month-by-month comparison of income vs expense

Report Types
------------

1. Expense Report
   - Category-wise expense breakdown
   - Total expense amount
   - Percentage per category
   - Daily/Monthly trend
   - Top spending categories

2. Income Report
   - Category-wise income breakdown
   - Total income amount
   - Percentage per category
   - Daily/Monthly trend

3. Monthly Comparison Report
   - Month-by-month income vs expense
   - Savings per month
   - Percentage change month over month
   - Bar chart comparing income and expense

---


Filter Options
--------------

Common filters for all reports:
   - Date From: date input, required
   - Date To: date input, required, must be >= Date From
   - Category: dropdown (optional, "All Categories" default)
   - Report Period: preset buttons (This Month, Last Month, This Year, Last Year, Custom)

Preset Periods:
   - This Month: first day to last day of current month
   - Last Month: first day to last day of previous month
   - This Year: Jan 1 to Dec 31 of current year
   - Last Year: Jan 1 to Dec 31 of previous year
   - Custom: user selects from and to dates

Monthly Comparison Report Details
----------------------------------

Table Format:
   | Month     | Income | Expense | Savings | % Change |
   | Jan 2026  | $5000  | $3000   | $2000   | -        |
   | Feb 2026  | $5200  | $3200   | $2000   | +4%      |
   | Mar 2026  | $4800  | $3500   | $1300   | -7.7%    |

   - Savings = Income - Expense
   - % Change = ((current - previous) / previous) * 100
   - Green for positive savings, red for negative
   - Green arrow up for positive change, red arrow down for negative

Charts:
   - Grouped bar chart: Income vs Expense per month
   - Line chart: Savings trend over months
   - Stacked bar chart: Category-wise expense per month (optional)

Performance Considerations
---------------------------

- Use indexes on user_id and date columns in transactions table
- Limit results for large date ranges (e.g., max 2 years at a time)
- Paginate transaction list tables
- Use COUNT queries instead of fetching all records for totals
- Consider data aggregation for very large datasets

IMPORTANT: Security Implementation Standards
==============================================

This module MUST follow these security practices in implementation:

1. Prepared Statements: ALL database queries MUST use PDO prepared statements with bound parameters. Never concatenate user input into SQL queries.
   Example: $stmt = $pdo->prepare("SELECT * FROM transactions WHERE user_id = :user_id AND date >= :date_from");
            $stmt->execute(['user_id' => $user_id, 'date_from' => $date_from]);

2. Input Sanitization: ALL user inputs must be sanitized before validation and database insertion.
   Example: $amount = filter_input(INPUT_POST, 'amount', FILTER_SANITIZE_NUMBER_FLOAT, FILTER_FLAG_ALLOW_FRACTION);
            $description = filter_input(INPUT_POST, 'description', FILTER_SANITIZE_SPECIAL_CHARS);

3. Output Escaping: ALL dynamic content rendered in views MUST be escaped using htmlspecialchars() to prevent XSS.
   Example: echo htmlspecialchars($transaction['description'], ENT_QUOTES, 'UTF-8');
            echo htmlspecialchars($category['name'], ENT_QUOTES, 'UTF-8');

4. Authorization Checks: Verify the logged-in user owns the resource before any operation.
   Example: if ((int)$transaction['user_id'] !== (int)$_SESSION['user_id']) { http_response_code(403); exit('Forbidden'); }

5. CSRF Protection: All POST/PUT/DELETE forms must include and validate CSRF tokens.
   Example: if (!hash_equals($_SESSION['csrf_token'], $_POST['csrf_token'])) { http_response_code(403); exit('Invalid CSRF token'); }

6. File Upload Security: Validate MIME type by extension and content, use random filenames, store outside web root if possible.
   Example: $allowed = ['jpg','jpeg','png','gif'];
            $ext = strtolower(pathinfo($_FILES['file']['name'], PATHINFO_EXTENSION));
            if (!in_array($ext, $allowed)) { reject; }
