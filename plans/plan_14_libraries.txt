Expense Tracker - Required Libraries & Dependencies Plan
=========================================================

Module Name: Libraries & Dependencies
File: plan_14_libraries.txt

---


Overview
--------
This file lists all external libraries, frameworks, and tools required for the project.
All libraries should be included locally in the assets/vendor/ directory or loaded via CDN.
For PHP libraries, use Composer if available, otherwise include manually.

---


Frontend Libraries
------------------

1. Bootstrap 5 (or Bootstrap 4)
   Purpose: CSS framework for responsive layout, components, grid system
   Version: 5.3.x (recommended) or 4.6.x
   Files needed:
     - CSS: bootstrap.min.css
     - JS: bootstrap.bundle.min.js (includes Popper.js)
   Usage: Navbar, sidebar, forms, buttons, modals, cards, tables, alerts, dropdowns
   CDN: https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css
   Local: assets/vendor/bootstrap/

2. jQuery
   Purpose: DOM manipulation, AJAX requests, event handling
   Version: 3.7.x
   Files needed:
     - JS: jquery.min.js
   Usage: All AJAX calls, form handling, dynamic UI updates
   CDN: https://code.jquery.com/jquery-3.7.0.min.js
   Local: assets/vendor/jquery/

3. Chart.js
   Purpose: Render charts for dashboard and reports (pie, bar, line charts)
   Version: 4.4.x
   Files needed:
     - JS: chart.min.js
   Usage: Dashboard expense breakdown, income vs expense trends, monthly comparison
   CDN: https://cdn.jsdelivr.net/npm/chart.js
   Local: assets/vendor/chart.js/

4. Bootstrap Icons (or Font Awesome)
   Purpose: Icon library for UI elements
   Version: 1.11.x (Bootstrap Icons) or 6.5.x (Font Awesome)
   Files needed:
     - CSS: bootstrap-icons.css or all.min.css
   Usage: Navigation icons, action buttons, category icons, status indicators
   CDN: https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.0/font/bootstrap-icons.css
   Local: assets/vendor/bootstrap-icons/ or assets/vendor/fontawesome/

5. DataTables (Optional but Recommended)
   Purpose: Enhanced HTML tables with sorting, searching, pagination
   Version: 2.0.x
   Files needed:
     - CSS: jquery.dataTables.min.css, dataTables.bootstrap5.min.css
     - JS: jquery.dataTables.min.js, dataTables.bootstrap5.min.js
   Usage: Expense list, income list, reports transaction tables
   CDN: https://cdn.datatables.net/2.0.0/css/dataTables.bootstrap5.css
   Local: assets/vendor/datatables/

---


Backend PHP Libraries
---------------------

1. Firebase PHP JWT
   Purpose: Generate and validate JSON Web Tokens for API authentication
   Version: 6.10.x
   Package: firebase/php-jwt
   Installation: composer require firebase/php-jwt
   Usage: AuthController login (generate JWT), AuthMiddleware (validate JWT)
   Notes:
     - Store JWT secret key in config.php as JWT_SECRET
     - Use HS256 algorithm
     - Set expiration to 1 hour for access tokens

2. PHPMailer (Optional)
   Purpose: Send emails for password reset, notifications, reports
   Version: 6.9.x
   Package: phpmailer/phpmailer
   Installation: composer require phpmailer/phpmailer
   Usage:
     - Forgot password email with reset link
     - Weekly/monthly summary emails (if notifications enabled)
   Alternative: PHP mail() function (simpler but less reliable)

3. Dompdf (Optional, for PDF export)
   Purpose: Generate PDF reports from HTML
   Version: 3.0.x
   Package: dompdf/dompdf
   Installation: composer require dompdf/dompdf
   Usage: ReportController exportPdf() method
   Alternative: TCPDF or mPDF

4. League CSV (Optional, for CSV export)
   Purpose: Read and write CSV files
   Version: 9.10.x
   Package: league/csv
   Installation: composer require league/csv
   Usage: ReportController exportCsv() method, Settings export
   Alternative: PHP fputcsv() (built-in, simpler)

CDN vs Local Files
-------------------

Recommendation: Use local files for production, CDN for development

Local (Production):
   - Download all vendor files to assets/vendor/
   - Reference with relative paths
   - Benefits: faster load, no external dependency, works offline

CDN (Development):
   - Use CDN links for faster setup
   - Benefits: no local files needed, automatic updates, caching across sites

Hybrid Approach:
   - Use CDN for Bootstrap, jQuery, Chart.js
   - Use local for custom CSS/JS
   - Fallback to local if CDN fails (optional)

Performance Optimization
------------------------

1. Minify all CSS and JS files
2. Combine CSS files into one stylesheet
3. Combine JS files into one script (except page-specific)
4. Enable gzip compression on server
5. Set proper cache headers for static assets
6. Lazy load Chart.js only on pages that need charts
7. Use image sprites for icons (or icon font)
8. Compress images in uploads directory

---


Security Libraries Notes
------------------------

1. JWT Library (firebase/php-jwt)
   - Use strong secret key (32+ characters)
   - Validate expiration and issuer claims
   - Store refresh tokens hashed in database

2. Password Hashing
   - Use PHP built-in password_hash() with PASSWORD_BCRYPT or PASSWORD_DEFAULT
   - Cost factor: 10-12 (default is fine for most cases)
   - Never use MD5, SHA1, or plain text

3. CSRF Protection
   - Generate token with random_bytes() or bin2hex()
   - Store in session
   - Validate with hash_equals() to prevent timing attacks

4. Input Validation
   - Use PHP filter_var() for sanitization
   - Use custom validation or Respect/Validation library (optional)
   - Always validate on server side (never trust client-side only)
