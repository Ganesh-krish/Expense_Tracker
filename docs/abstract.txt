EXPENSE TRACKER
PROJECT ABSTRACT

The Expense Tracker is a web-based personal finance management application developed to help individuals monitor, record, and analyze their daily income and expenses. Traditional tracking methods such as spreadsheets and manual records are often cumbersome, insecure, and lack actionable insights. This project provides a centralized digital solution with secure user authentication, transaction categorization, budget management, interactive reports with export options, receipt uploads, and recurring transaction support. Built using PHP 8.x, MySQL, Bootstrap 5.3, and jQuery with an MVC architecture, the application ensures scalability, maintainability, and security through CSRF protection, bcrypt hashing, and prepared statements. The system enables users to gain clear visibility into their spending habits, adhere to budgets, and make informed financial decisions through an intuitive and responsive web interface designed for both desktop and mobile devices.
